### 🔄 Data Flow

1. **User starts processing** → Frontend calls `/api/process`
2. **Backend creates Celery task** → Returns task_id
3. **Frontend subscribes to WebSocket** → `socket.emit('subscribe', {task_id})`
4. **Celery worker executes** → Calls `workflow.py` functions
5. **Progress updates** → `emit_progress()` → WebSocket → Frontend
6. **Logs** → `emit_log()` → WebSocket → LogTab
7. **Completion** → `emit_completed()` → WebSocket → StatusBar

### 🚀 Advantages vs Tkinter

| Feature | Tkinter (Old) | Web (New) |
|---------|---------------|-----------|
| UI Blocking | ❌ Freezes during processing | ✅ Always responsive |
| Real-time Updates | ❌ Polling | ✅ WebSocket push |
| Scalability | ❌ Single process | ✅ Multiple workers |
| Deployment | ❌ Desktop only | ✅ Docker + Cloud |
| Mobile Support | ❌ No | ✅ Responsive design |
| Modern UI | ❌ Tkinter widgets | ✅ React + Tailwind |
