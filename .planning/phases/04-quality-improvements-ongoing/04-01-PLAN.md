<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| User input → File system | User-provided file paths could traverse directories |
| User input → Subprocess | User-provided URLs passed to yt-dlp and ffmpeg |
| Log output → File system | Log messages may contain user-provided data |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-01 | Information Disclosure | logger.py | mitigate | Sanitize user input before logging - avoid logging tokens, passwords, or full file paths with sensitive data |
| T-04-02 | Tampering | error messages | mitigate | Don't expose internal paths or system info in user-facing error messages - use generic messages in GUI, detailed info only in log file |
| T-04-03 | Denial of Service | log file growth | mitigate | Use RotatingFileHandler with 10MB limit and 3 backups to prevent disk exhaustion |
</threat_model>
